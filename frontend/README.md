# HospitalShield AI — dashboard

React 19 + TypeScript (strict) + Vite + Tailwind CSS v4 + Recharts + React Router.

```bash
npm install
npm run dev        # http://localhost:5173 (proxies /api to 127.0.0.1:8000)
npm test           # component tests (Vitest + Testing Library)
npm run build      # type-checks strictly, bundles to dist/
npm run types      # regenerate src/types/api.ts from ../frontend/openapi.json
```

The dashboard renders only what the backend computes; the offline fallback
(`public/demo-results.json`, regenerated by `backend/scripts/generate_demo_snapshots.py`)
shows precomputed data with editing disabled when the API is unreachable.
